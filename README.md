# Portafolio Profesional de Ingeniería y Desarrollo

Bienvenido a mi repositorio central de proyectos. Este espacio recopila desarrollos de software, simulaciones de ingeniería, modelos de analítica de datos, estadística aplicada y diseños técnicos orientados a resolver problemas complejos con rigor técnico.

---

## 📂 Estructura del Portafolio

El repositorio está organizado en las siguientes categorías principales:

| Categoría | Descripción | Tecnologías / Herramientas |
| :--- | :--- | :--- |
| **[01. Desarrollo de Software](./01_Desarrollo_Software)** | Aplicaciones de escritorio, utilidades de automatización y herramientas de ciberseguridad. | Python, Tkinter, Git |
| **[02. Simulación de Procesos](./02_Simulacion_Procesos)** | Modelado, simulación y optimización de sistemas industriales y de procesos. | Aspen HYSYS, CFD, Flexim |
| **[03. Analítica y Estadística](./03_Analitica_Datos_Stats)** | Modelado estadístico, diseño de experimentos (DoE), optimización por RSM y análisis de datos. | R, Python (Pandas/NumPy) |
| **[04. Diseño Técnico y CAD](./04_Diseno_CAD)** | Planos de ingeniería, diagramas de flujo y esquemas técnicos. | AutoCAD, Visio |

---

## 🚀 Proyectos Destacados

### 🔐 App Cifrado César (en `01_Desarrollo_Software/App_Cifrado_Cesar`)
Herramienta de escritorio desarrollada en Python con interfaz gráfica (`tkinter`), diseñada con fines educativos en ciberseguridad. Permite aplicar el cifrado y descifrado César de forma universal sobre archivos de texto (`.txt`), documentos de Word (`.docx`) y archivos PDF (`.pypdf`).
